RSATB Random-state ab-initio tight binding Version 0.1 · Apache 2.0

Electronic structure
of large systems,
from random states.

RSATB computes densities of states, conductivities, optical spectra and real-space electron densities from tight-binding and DFT Hamiltonians. Instead of diagonalizing the Hamiltonian, it combines stochastic trace estimation with Chebyshev expansions, so the cost scales linearly with the number of atoms. A calculation is described by one JSON input file. 

rsatb template sktb -o run.json   # write an example input
rsatb check run.json              # validate it
mpirun -n 64 rsatb run run.json   # run: serial, or MPI + OpenMP
