RSATB Random-state ab-initio tight binding Version 0.1 · Apache 2.0

Electrons, counted
one random state
at a time.

RSATB computes the electronic properties of very large systems — densities of states, conductivities, optical spectra, maps of where the electrons sit — from a tight-binding or DFT Hamiltonian and a short JSON file. It never diagonalizes. It follows a handful of random states instead, so its cost grows only in proportion to the number of atoms.

I

In three commands

  1. rsatb template sktb -o run.json

    Begin from a working input: where the atoms are, what the Hamiltonian is, and what to compute.

  2. rsatb check run.json

    Every key, file and request is verified before anything runs. A typo is an error with a suggestion, never a silent default.

  3. mpirun -n 64 rsatb run run.json

    The same file runs on a laptop or across a cluster. Results are written as NumPy archives, with a summary of exactly what was computed.

Inputs can be written and checked anywhere Python runs; only the final command needs the compiled solver.
